# Zero Trust Cloud Architecture on AWS

## Overview
This project demonstrates implementation of a Zero Trust cloud architecture using Amazon Web Services (AWS).

The infrastructure follows security best practices including:
- Network segmentation
- Least privilege access
- No direct SSH exposure
- Centralized logging and monitoring

---

# Architecture

## Components
- Custom VPC
- Public subnet
- Private subnet
- Internet Gateway
- Route Tables
- Security Groups
- AWS Systems Manager (SSM)
- AWS CloudTrail

---

# Security Features

## Zero Trust Principles
- No public SSH access
- Session Manager for secure administration
- Isolated subnets
- Security group-based access control
- IAM least privilege
- Centralized audit logging
